# Simplified Retrieval-Augmented Generation (RAG) and Website Development on AWS

## Overview

This project provides a simplified implementation of Retrieval-Augmented Generation (RAG) and website deployment on AWS. The RAG model enhances the response quality of a generative model by incorporating external knowledge retrieved from a dataset.


## Technologies Used

LangChain (for retrieval and generation)

Vector Databases (Chroma)

Flask (for backend API)

React.js / Next.js (for frontend development)

### AWS Services:

Amazon S3 (for storage)

Amazon EC2 / Lambda (for computation)

Amazon API Gateway (for API management)

Amazon Route 53 (for domain name management)
